# 青崖山常驻地图与对话事件 · 第一阶段

新增玩家闭环：地图 → 地点 / NPC → 对话 → 安排与结果 → 地图。H5 和抖音 Canvas 共用 `src/data/town.ts`；现有剧情仍由 StoryEngine 推进。

## 入口与内容

首页「青崖山地图」可先看导览，未抵达地点显示开放条件。首次进入 EP13 自动回营地；以后从首页继续游戏进入营地。营地「继续主线」接回原节点，剧情页可返回营地。

| 地点 | 开放时点 | 事件 |
| --- | --- | --- |
| 游客中心 | EP13 | CR-07 信息边界、居民需求台账 |
| 北门湿林 | EP14 | 警戒与生态观察 |
| 泵房 | EP15 | 赵建国巡查、取水秩序 |
| 公共食堂 | EP16 | 分餐与厨余管理 |
| 医务点 | EP16 | 周芸物资交接与轮休 |
| 百鬼街 | EP30 | 摊娘与检查范围协商 |
| 索道站 | 未开放 | 明示安全检查未完成 |

这是根据主线衍生的营地短对话，不冒充原文台词。EP 编号以当前 35 段运行剧本为准。百鬼街对话不会提前设置街契、消防等主线标志。

安排只影响现有六项营地指数，每项 +3，上限 100。`flags['town:'+地点ID]` 存选择序号，结果可随时回看，同周目不重复结算。沿用现有自动存档与检查点；恢复较早检查点时指数和记录一同回退，新周目清空营地安排。不会修改主线节点、观察档案或剧情选择历史。

## 素材

从用户 `scripts/UI/` 中选取透明图集，完整复制至 `src/static/scenic/town/`，前端按矩形区域取样，不截取参考界面，不添加白底。对应来源：

- `props.png` ← `525ce0a9-0f38-44cd-af9d-c64f0f41617a.png`：公告板、取水设施、物资箱、湿林与电箱。
- `buildings.png` ← `5ff0249c-91b8-4a51-89a2-cd37f90500aa.png`：食堂与百鬼街建筑示意。
- `xuzhiwei.png` ← `0d9564c1-a53e-4fd2-ba91-b473711223e3.png`：许知微半身像和地图人物。

当前地图为可交互的景区导览示意，不是精确工程地形。网页人物有缓慢移动装饰并尊重减少动态效果偏好，尚无寻路与碰撞。抖音构建时压缩整张透明图集，取样坐标按实际分辨率换算。

## 后续八类页面的边界

主城保留为常驻层，NPC 对话是可关闭的事件层；已有主线、CG / 媒体能力继续复用。不为尚未实现的玩法放置可点击空入口。下一阶段再加入建筑升级、室内调查和一项基建小游戏，然后实现奖励回写地图。正式影片到位后再接开始静帧 → 播放 → 结束静帧 / Choice → 营地结果的衔接。

本阶段未实现生产收取、派人、拖拽合同或施工小游戏，也没有新增假视频。抖音真机验证仍待实际 AppID。

## 验证

`npm run verify:base` 包含地图解锁、记录保存、重复选择防刷、资源上限、主线隔离、新周目重置及横竖屏各页面触摸边界。浏览器检查地图热点、锁定提示和半身像对话布局。
