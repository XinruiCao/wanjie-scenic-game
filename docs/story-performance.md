# 对话与剧情图演出

11 段交流场景采用底部对话框和放大许知微立绘：V_M01、EP03、EP04、EP06、EP08、EP10、EP13、EP15、EP17、EP30、EP34。其他段落保留原大幅剧情图与选择排版；不把全部段落强制改成对话。

`src/data/story-performance.ts` 为两端共享的演出层：原剧情说明分段作为旁白，原 quote 作为许知微台词；EP03 的明确引语单独标为 CR-07。未给不确定的旁白擅自指定说话人。剧情结构、选择奖励和章节跳转规则不变。

立绘使用已接入的 UI 透明图集 `0d9564c1-a53e-4fd2-ba91-b473711223e3.png`，以不同姿态表达平静、担忧和坚定。当前不是实时面部动画，也未为其他 NPC 冒用许知微立绘；说话人显示在对话框中，非许知微说话时立绘作为她的现场反应。

供水段落增加 UI 文件夹 `610f8791-646f-46f8-9e34-b781f71e07c2.png` 的透明水纹素材，复制到 `src/static/scenic/town/water.png`。系统连接使用青色信息光效，重逢和签约使用暖色氛围。网页可在对话框关闭特效，并尊重系统减少动态效果；小游戏沿用设置中的减少动态效果。无闪屏、剧烈抖动或强制播放音效。

每段演出提供上一句与下一句。`flags['beat:'+节点ID]` 保存已读位置，与原存档及检查点一起持久化；读句子不推进主线、不改变资源。最后一句后才能打开关键选择；返回对话不清除进度。选项结果仍由 StoryEngine 应用。新周目清空本周目阅读位置。

H5：`StoryPerformance.vue`；Canvas：`GameApp.performance()`。横竖屏都为背景图、角色、下部对话层；短横屏让角色占左侧，对话位于右下，正文与按钮区域可滚动。

验证：`npm run verify:base` 覆盖句子边界、读档恢复、上一句、主线与资源不变、新周目重置、对话末尾才出现选择、横竖屏按钮可达性。保留手游 V1.0 标签，演出迭代继续提交 main。
