# 基础试玩版 v1.0.0

2026-09-17，作为后续功能开发的基础版本保存。对应 Git 标签 `v1.0.0-base`。

## 交付范围

- 《青崖山开门》第一卷 35 段图文剧情、条件选择、三个卷末方向。
- 六项重建指数、建设手记、12 项生态观察、6 个建设里程碑。
- 自动存档、异常存档恢复、重新开始与跨周目外观解锁。
- 纸白 / 黑金双皮肤；完成 EP12 进入 EP13 解锁黑金。
- H5 与抖音 Canvas 两端；手机横竖屏重排，不重置剧情。
- 场景概念图和独立透明装饰素材，按钮填色沿内框裁切。

## 可复现验收

Node.js 22+，执行 `npm ci` 和 `npm run verify:base`。

自动检查覆盖主线可达性、各卷末方向、资源边界、编辑器一致性、解锁规则、存档异常、横竖旋转状态保持、旧触摸取消、传感器防抖、宿主拒绝转屏、媒体生命周期和 tt 环境启动。网页与 Canvas 已做横竖屏浏览器预览验证。

GitHub Actions 提供 `wanjie-h5-base` 和 `wanjie-douyin-base` 构建产物。抖音产物解压后导入含 `game.js` 的目录；H5 产物使用静态 HTTP 服务运行。

## 后续发布工作

本版没有正式影片、云存档、广告或支付。素材是概念场景，部分剧情共用场景，并非逐镜头成片。App 与抖音尚未真机验收，抖音还需实际 AppID、账号及平台必需能力接入。详见 [抖音说明](douyin-mini-game.md)。

`npm run check:douyin` 是正式发行检查，当前预期不通过；它与基础试玩版验收分开。
