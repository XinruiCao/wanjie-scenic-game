# 手游 V1.0

当前版本名称：手游 V1.0。软件版本号：1.0.0。Git 标签：`v1.0.0-mobile`。

本版本固定地图与 NPC 对话阶段的交付成果：第一卷 35 段剧情、双皮肤解锁、本机存档、横竖屏适配、青崖山地图、六处剧情解锁地点与一次性对话结果。网页及抖音 Canvas 共用剧情和营地逻辑。

地图功能提交为 `e724e60`，该版本标签另包含版本名称与元数据统一。早先的 `v1.0.0-base` 基础版标签保留不变。

这是项目版本标记，不代表已在应用商店或抖音正式上线。抖音仍为 demo 配置，实际 AppID、平台接入与真机验收待完成。详见 [营地事件](town-events.md) 和 [抖音说明](douyin-mini-game.md)。
