# Story Studio 导演工作台

同一仓库中的独立 Vue 应用，保留原游戏目录，不注册到 `src/pages.json`。只监听本机 `127.0.0.1:5174`，API 仅在编辑器开发服务中存在。游戏构建不包含编辑器、草稿、回收站、布局或制作备注。

```sh
npm run story:studio
```

打开 http://127.0.0.1:5174 。在较窄的窗口用顶部「素材」「属性」打开侧栏。

- 左键拖动卡片改变位置；按住鼠标中键在画布任意位置拖动可平移（包括卡片和连线上），也可左键拖动空白画布；滚轮缩放。
- 从卡片右侧圆点拖到目标卡片，设置播放结束或选项跳转；拖箭头前的圆点可重接目标。
- 右键节点上传/替换视频、增加选择、增加视频或互动页、移到回收站；右键连线可修改目标或断开。
- 右键节点或连线可设置颜色，也可在属性面板设置。支持六种预设色、自定义色、恢复默认和撤销/重做；颜色随草稿保存，仅用于后台标记。
- 视频或素材库条目可直接拖进画布。本地视频复制到 `src/static/videos/studio`，浏览器抽帧生成封面；不支持解码的格式仍可上传，但需转码后才可在游戏中播放。
- 属性面板编辑标题、章节、互动页面内容、选项文字和目标。既有条件、FLAG、统计与证据效果完整保留；复杂条件仍在工程 JSON 中编辑。
- 保存草稿写入 `story-project/story.project.json`。草稿允许暂时断线。
- 发布会先保存草稿，再校验并生成 `src/data/story.runtime.json`，游戏引擎直接使用该文件。重新构建/发布游戏才对玩家生效。
- 制作备注 `notes`、布局 `layout` 和回收站 `trash` 不进入运行数据。这里的隔离保护制作工具和备注；游戏运行必需的剧情数据本身仍在玩家包中。
- 撤销/重做支持最近 60 步，快捷键 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。撤销历史属于当前会话；回收站随草稿保存，重开后可恢复节点，但需重新连接路线。

```sh
npm run story:check       # 检查草稿引用、入口可达性、能否到达结束节点、缺失素材
npm run story:publish     # 校验并生成运行数据
npm run validate:story    # 原游戏六结局、条件和存档回归
npm run story:build       # 仅检查编辑器前端构建，静态产物不含本地写入 API
npm run build:h5          # 正式玩家端构建
```

当前基线有 45 个节点，视频文件尚未提供，已有场景图作为封面。缺失视频会提示，不阻止使用游戏已有的无视频回退流程；断线、无法到达的节点及无法结束的路线会阻止发布。校验不等同于穷举所有 FLAG 组合；大幅调整带条件的路线后仍需实机试玩。

目前支持游戏已有的互动页面类型和六个结局。增加全新互动机制或新结局定义仍需同步游戏渲染器/EndingEngine。建议单个编辑器窗口编辑，避免多个窗口互相覆盖。
